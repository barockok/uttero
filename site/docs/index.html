1. Install

You need macOS 26 or later (Apple silicon or Intel) and Claude Code, with claude on your PATH and signed in.

  1. Download uttero 0.1.11, open the DMG and drag uttero to Applications.
  2. Open uttero. It lives in the menu bar and has no Dock icon.
  3. On first launch a welcome guide walks you through the microphone, the wake phrase, your voice and the Claude Code plugin. You can replay it from Settings › General › Welcome guide.

The app is signed with a Developer ID and notarized by Apple.

2. The Claude Code plugin

The plugin lets each Claude Code session send its approvals and updates (finished, waiting, needs attention) to uttero. Without it, uttero can still message your sessions, but it won't hear back from sessions it didn't start.

Install it from the uttero menu with Install the Claude Code Plugin, or yourself:

claude plugin marketplace add barockok/uttero
claude plugin install uttero@uttero

Restart Claude Code sessions that were already open so they load it. When uttero isn't running, the plugin stays silent and Claude Code behaves as usual.

3. Voice setup

Voice calls use OpenAI GPT-Live. Add your OpenAI API key in Settings › Voice; it's stored in your Keychain. uttero also picks up OPENAI_API_KEY from your login shell.

OpenAI bills your key while a call is open, so uttero hangs up after a quiet period (30 seconds to 5 minutes, set in Settings › Voice). Typed messages to uttero don't need a key.

In Settings › Voice you can also choose the voice, the microphone and the speaker (System Default follows Control Center, including earphones that connect later), and turn on echo cancellation so you can use speakers.

The wake phrase is recognized on your Mac by Apple's speech recognizer. Nothing is sent until you say it. Pick a phrase made of real words; invented words are recognized poorly. With the wake phrase off, uttero doesn't use the microphone outside a call.

During a call, a call bar floats at the top of the screen with mute, hang up and any pending approval. You can turn it off in Settings › General.

5. Sessions

uttero sees the Claude Code sessions on your Mac, in terminals and in the background. Ask it things like:

  • “What's running?” or “Which sessions are waiting on me?”
  • “Switch to web-app.” (uttero focuses that session; what you say next goes there)
  • “Start a session in ~/code/api-server and fix the failing test.”
  • “Stop the docs session.”

Sessions uttero starts are its own: it follows their progress and tells you when they finish or get stuck. Sessions you started yourself stay yours; uttero messages them only when you ask. You can also start one with New Session… in the menu.

Claude Code refuses to start a background session in a folder you haven't trusted yet. Open Claude Code in that folder once, or uttero will tell you it couldn't start.

6. Approvals

When a session with the plugin wants to run a tool that needs your permission, uttero asks you: out loud during a call, in the call bar, in the menu, or as a notification with Allow and Deny. The terminal dialog stays open at the same time; whichever you answer first wins. If you don't answer in time, the terminal dialog stays and nothing runs.

For safety, a spoken approval needs a clear answer (“yes, allow it” / “no”). Anything unclear is asked again.

By default, sessions uttero starts (and the manager itself) skip permission prompts, and the manager confirms sending, deleting or pushing with you first. Turn off Settings › Manager › Skip permission prompts to approve every tool call.

7. Memory

uttero is one long-lived manager. It keeps notes as plain Markdown in ~/.uttero-osx/memory/: a curated MEMORY.md, daily notes and one file per project. It writes down durable things it learned (not secrets or routine progress). Say “forget that” to remove something, or edit the files yourself.

To start over, use Settings › Manager › Start fresh. Your sessions keep running.

With Inherit my Claude Code profile (the default), the manager loads your MCP servers, connectors and plugins for quick lookups like your calendar or the web, and hands project work to sessions.

9. Updates

uttero updates itself. Use Check for Updates… in the menu, or leave automatic checks on in Settings › General. Updates are signed; uttero only installs ones that match its key.

Versions 0.1.5 and older have no updater: download the latest DMG once by hand.

10. Troubleshooting

Sessions don't send approvals or updates

Check the plugin is installed (claude plugin list) and restart sessions opened before you installed it.

uttero says it can't find Claude Code

uttero reads your PATH from your login shell. Make sure claude runs in a new Terminal window, then quit and reopen uttero.

The wake phrase doesn't trigger

Check uttero has Microphone and Speech Recognition access in System Settings › Privacy & Security. Try a phrase of two common words. Audio played by the Mac itself is cancelled out on purpose, so a video saying the phrase won't wake it.

No sound after switching headphones

Choose System Default in Settings › Voice, or pick the device there.

Logs

The core writes to ~/Library/Logs/uttero/core.log. Include it when you report an issue.

11. Uninstall

claude plugin uninstall uttero@uttero
claude plugin marketplace remove uttero
rm -rf ~/.uttero-osx

Then drag uttero from Applications to the Trash. Your OpenAI key stays in the Keychain until you remove it in Keychain Access or Settings › Voice.
