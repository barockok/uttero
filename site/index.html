What it does

One voice for all your sessions.

Every session

Ask what's running, hop between sessions, or say “start a session in api-server and fix the failing test.”

Approve by voice

When a session needs permission, uttero asks you out loud or with an Allow / Deny notification.

On your Mac

The wake phrase is recognized on-device. No servers, no account. Or just press Option-Space.

Get started

Three steps.

01

Download

Get the DMG, open it and drag uttero to Applications.

02

Add the plugin

In the uttero menu, click Install the Claude Code Plugin. Restart open sessions.

03

Add your voice key

Paste your OpenAI API key in Settings › Voice. Typing works without it.

Needs macOS 26+ and Claude Code signed in. Using Homebrew? brew install --cask barockok/tap/uttero. Plugin from the terminal: claude plugin marketplace add barockok/uttero then claude plugin install uttero@uttero. More in the docs.
